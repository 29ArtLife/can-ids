# src

源代码。按职责分层，层与层之间只通过数据文件衔接。

| 模块 | 职责 | 负责 |
|---|---|---|
| `io/` | 各数据集解析器，输出统一字段 | A |
| `features/` | 频率、周期、载荷统计、频域特征 | B / C |
| `models/` | 随机森林、CNN-LSTM、改进方法 | B |
| `experiments/` | 训练与评测入口，写 runs.csv | B / C |
| `api/` | 检测原型的后端 | D |

约定：

- 每个模块只暴露少量函数，内部实现可以随意改
- 所有随机性必须接受显式 seed 参数
- 不要在模块里写死路径，路径由调用方传入
